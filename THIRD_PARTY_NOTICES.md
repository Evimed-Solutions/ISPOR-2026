# Third-party dependencies

This package does not vendor external Python/R libraries, software binaries, fonts, logos, or published figures. Install dependencies from their original distributions, which supply their own licence and copyright notices.

The colour diagnostics call the installed **SurvdigitizeR** package (MIT + file LICENSE). Its installed copyright metadata names **Juan David Rios, 2021**. The pinned source revision is recorded in `DEPENDENCIES.md`. The **cluster** package is licensed under **GPL (>= 2)**. These packages are used as external dependencies; their source code is not copied into this repository.

Poppler is also an external dependency, obtained separately. Consult the notices and licence files included with its distribution and those of each Python dependency. Windows Arial fonts are supplied by the user's Windows installation and are not included here.

No licence has been selected for the project-owned code or synthetic study data in this review copy. Dependency notices do not select a licence for this project.
