# Retained figures

`baseline_comparison.png` has four rows, from top to bottom: **baseline 300 DPI**, **JPEG quality 95**, **blur sigma 1.5**, and **screenshot/slide**. The two columns show pixel change (left) and algorithmic arm groups with the observed replicate 1 trace (right). Its row labels were separate objects on the original poster; the row order is stated here so the standalone image can be read without that document. The corresponding key is `baseline_comparison_legend.png`, and the source numbers and crop dimensions are in `baseline_comparison_values.csv`.

`full_plot_baseline.png` shows the complete baseline plot and observed digitised points. `full_plot_baseline_zoombox.png` adds the box corresponding to the comparison's early-time crop. Both have SVG versions. Censor marks are enlarged for readability; `full_plot_baseline_validation.json` records this display scaling, point counts and geometry checks. They are not new extraction observations.

`baseline_comparison.svg` contains the same four comparison rows as editable vector paths, trace markers, callouts and text, with no embedded bitmap. Its producer reads the clustering intermediates generated by `python run.py figures`.

`baseline_original_4p72x5p69in.png/.svg` shows the original baseline curves and censor marks, with Control/Treatment in the upper-right legend, and no digitised overlay, auxiliary key or zoom box. The physical size is 4.72 × 5.69 inches; the PNG is 1416 × 1707 pixels at 300 DPI. Tick and legend fonts are 19 pt, and axis labels are 21 pt. The adjacent JSON records these settings.
